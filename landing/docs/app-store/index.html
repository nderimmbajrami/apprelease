    App Store Connect publishing

    AppRelease uploads the .ipa to App Store Connect, waits for processing, and can add it to TestFlight groups or submit it for App Store review.

    Requirements

    • An App Store Connect API key added under Integrations (see iOS code signing).
    • The app created in App Store Connect with the same bundle identifier.
    • A build signed for app_store distribution.

    Configuration

    workflows:
  ios-workflow:
    publishing:
      app_store_connect:
        auth: integration              # the key from Team settings → Integrations
        submit_to_testflight: true
        beta_groups:                   # optional
          - Beta testers
          - QA
        expire_previous_builds: false  # optional
        submit_to_app_store: false
        release_type: AFTER_APPROVAL   # MANUAL | AFTER_APPROVAL | SCHEDULED
        copyright: 2026 Example Ltd
    KeyDefaultDescription
    authintegrationUse the team's API key. Alternatively give api_key, key_id, issuer_id as variable references.
    submit_to_testflightfalseUpload and wait for processing.
    beta_groups—External or internal groups to add the build to. External groups trigger beta review.
    expire_previous_buildsfalseExpire older TestFlight builds of the same version.
    submit_to_app_storefalseCreate (or reuse) the App Store version and submit for review.
    release_typeMANUALHow the version is released after approval.

    What the publishing step does

    1. Validates the .ipa and uploads it with the API key.
    2. Polls App Store Connect until the build has finished processing (usually 2–10 minutes).
    3. Sets the "What to test" text from release_notes.txt if present.
    4. Adds the build to the named beta groups.
    5. If submit_to_app_store is on, creates the version, attaches the build and submits.
    Export compliance. If the app does not use non-exempt encryption, add ITSAppUsesNonExemptEncryption = NO to Info.plist. Otherwise every TestFlight build waits for a manual answer in App Store Connect.

    Common errors

    MessageUsually means
    The bundle version must be higher than the previously uploaded versionUse versioning: source: app_store_connect.
    Missing ComplianceSet ITSAppUsesNonExemptEncryption in Info.plist.
    Invalid Provisioning ProfileThe build was signed for ad hoc or development. Use distribution_type: app_store.

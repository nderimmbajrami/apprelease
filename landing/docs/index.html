    How the pieces fit together

    AppRelease has three parts. The console at publish.apprelease.store is where apps, credentials and releases live. The runner is the machine that checks out your code, builds and uploads. And apprelease.yaml in your repository tells the runner what to do.

    A release starts in the console (or from a push, once triggers are on). The runner claims it, fetches the credentials the workflow names, runs the scripts, publishes the artifacts and streams the log back. When it is done you get an email.

    Coming from Codemagic? The file structure is deliberately similar. Rename codemagic.yaml, swap CM_ variables for AR_ and check the reference for the few keys that differ.

    Getting help and support

    Email — support@apprelease.store, answered within a business day.
    In the console — every failed release has a "Send to support" button that attaches the log.
